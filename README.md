# SafeMaint

SafeMaint 3차 프로젝트의 공동 개발 저장소입니다.

## 협업 방법

1. 저장소를 로컬 환경에 복제합니다.
2. 기능별 브랜치를 생성해 작업합니다.
3. 작업 내용을 커밋하고 GitHub에 푸시합니다.
4. Pull Request를 생성해 검토 후 `main` 브랜치에 병합합니다.

## 브랜치 규칙

- `main`: 검토가 완료된 코드를 관리하는 기본 브랜치
- 기능 개발 브랜치: `feature/기능명`
- 버그 수정 브랜치: `fix/수정명`

프로젝트 세부 내용과 실행 방법은 개발이 진행되는 대로 추가합니다.
