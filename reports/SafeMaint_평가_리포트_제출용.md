# SafeMaint AI 평가 리포트

---

## 1. 개요

SafeMaint는 산업 현장의 설비 정비·안전 작업을 지원하는 AI 어시스턴트로, 제조사
매뉴얼 검색(RAG), 사진 기반 부품 식별, 사고 유형 분류, GPS 기반 보호구(PPE)
체크리스트, 음성 안내를 제공한다.

모델을 직접 재학습하는 대신, **각 기능의 출력물을 독립된 평가 기준으로 채점**하는
방식을 택했다. 매 응답이 나올 때마다 별도의 평가 모델·정답셋·로그 집계를 거쳐
점수를 남기므로, 평가자의 주관이 아니라 정량 지표로 품질을 판단할 수 있다.

```
사용자 입력 (텍스트 질의 / 사진 / 음성 / GPS 좌표)
        │
        ▼
   SafeMaint 시스템
        │
        ├─ 매뉴얼 답변   → Ragas 평가        → Faithfulness / Answer Relevance / Context Precision·Recall
        ├─ 대화 응답     → G-Eval 평가       → 일관성 · 유용성 · 자연스러움 · 안전성
        ├─ 사진 분석     → 정답 라벨 대조     → 매칭 정확도 · 오추정 방지율
        ├─ 사고 유형 분류 → 라벨셋 대조       → Accuracy · F1
        ├─ GPS·PPE 판정  → 정답 좌표셋 대조   → 판정 정확도
        │
        ▼
   사용자 화면·음성       → 서버 로그         → 응답 속도 · 음성 인식/합성 정확도 · 완료율
```

## 2. 평가 대상

### 2-1. 평가 대상 모델

| 기능 | 모델 | 역할 |
| --- | --- | --- |
| 매뉴얼 검색(임베딩) | BAAI/bge-m3 | 매뉴얼 문서를 벡터로 변환해 검색 |
| 답변 생성 | GPT-4o-mini | 검색된 근거를 바탕으로 답변 작성 |
| 사고 유형 분류 | Qwen3.5-9B 파인튜닝 모델 | 사고 상황을 끼임·불시기동·감전·화재로 분류 |
| 사진 분석 | SigLIP + Qwen(정밀 분석) | 카탈로그 사진에서 제조사·모델·부품 식별 |
| 음성 인식(STT) | faster-whisper | 사용자 음성 질의 인식 |
| 음성 합성(TTS) | Supertonic | 답변 음성 합성 |

답변 생성에는 GPT-4o-mini를 쓰고 있으므로, 채점은 이보다 판단력이 높은 별도의
심사 모델(GPT-4o 또는 Claude)로 진행해 자기 채점(self-grading) 편향을 배제한다.

### 2-2. 테스트셋 구성

| 구분 | 규모(계획) | 구성 |
| --- | --- | --- |
| 매뉴얼 RAG 질의셋 | 30~50개 | 매뉴얼 전문형 40% · 부품 정의형 20% · 정비 절차형 25% · 근거 밖 질문 15% |
| 안전 오탐지 케이스 | RAG 질의셋에 10% 내외 포함 | 근거 없이 작업을 임의 승인하는지 확인하는 전용 케이스 |
| 사고 유형 분류 평가셋 | 50개 이상 | 학습에 쓰이지 않은 held-out 사고사례, 유형별 균형 구성 |
| 사진 매칭 평가셋 | 35장 | 선명한 사진 · 가려짐/흐림 사진 · 유사 모델 혼동 사진 · 표 포함 |
| GPS·PPE 판정 케이스 | 5개 이상 | 반경 안/경계/밖 조건별 판정 |
| 음성 평가셋 | 25개 | 일반 문장 · 안전 전문용어 포함 문장 · 장문 |

## 3. 평가 항목 및 목표

| 구분 | 지표 | 정의 | 목표 |
| --- | --- | --- | --- |
| 매뉴얼 검색 | Faithfulness | 답변이 검색된 근거에 실제로 기반하는 비율 | ≥ 0.8 |
| 매뉴얼 검색 | Answer Relevance | 질문 의도에 답변이 얼마나 직결되는가 | ≥ 0.8 |
| 매뉴얼 검색 | Context Precision | 검색된 근거 중 실제로 쓸모 있었던 비율 | ≥ 0.7 |
| 매뉴얼 검색 | Context Recall | 정답에 필요한 근거를 실제로 가져왔는가 | ≥ 0.7 |
| 매뉴얼 검색 | 출처 표기 정확도 | 답변에 표기된 파일명·페이지가 실제 근거와 일치하는가 | 100% |
| 대화 품질 | 일관성 | 근거·맥락을 유지하는가 | ≥ 4.0 / 5.0 |
| 대화 품질 | 유용성 | 사용자의 의도를 해결하는가 | ≥ 4.0 / 5.0 |
| 대화 품질 | 자연스러움 | 현장 안전관리자처럼 자연스러운가 | ≥ 4.0 / 5.0 |
| 대화 품질 | 안전성 | 확인되지 않은 위험 상태를 임의로 승인하지 않는가 | ≥ 4.5 / 5.0 |
| 사진 분석 | 매칭 정확도(Top-3) | 제조사·모델·부품명 일치율 | ≥ 85% |
| 사진 분석 | 오추정 방지율 | 가려지거나 흐린 정보를 추정하지 않고 확인 요청으로 처리하는 비율 | 100% |
| 사고 분류 | Accuracy | 전체 라벨 중 정답 비율 | ≥ 85% |
| 사고 분류 | 유형별 F1 | 끼임·불시기동·감전·화재 각각 | ≥ 0.8 |
| GPS·PPE | 근접 판정 정확도 | 반경 안/밖 판정이 정답과 일치하는 비율 | 100% |
| GPS·PPE | 보호구 매핑 정확도 | 설비별 필요 보호구 목록이 현장 검수본과 일치하는가 | 100% |
| 음성 | 인식/합성 정확도(CER) | 음성↔텍스트 변환 오차율 | ≤ 10% |
| 응답 속도 | 첫 응답까지 걸리는 시간 | 질의 후 첫 응답이 나오기까지 | ≤ 1.5초 |
| 완료율 | Task Completion Rate | 체크리스트 완료 세션 비율 | ≥ 80% |

## 5. 종합 의견

- 매뉴얼 검색과 대화 품질은 SafeMaint의 핵심 가치(정확한 근거 기반 안내)와 직결되므로
  최우선으로 측정한다.
- 안전성 지표는 단일 실패(근거 없이 작업을 임의 승인하는 사례)가 발생하면 전체
  평가 결과와 무관하게 개선이 필요한 항목으로 별도 관리한다.
- 사고 유형 분류기는 학습에 사용된 데이터와 겹치지 않는 평가셋을 확보하는 것이
  선행 과제다.
- 응답 속도·완료율은 별도 개발 없이 서버 로그만으로 측정 가능해 상대적으로 빠르게
  결과를 낼 수 있다.
